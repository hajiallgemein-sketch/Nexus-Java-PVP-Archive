# Nexus-Java-PVP-Archive
The Addon of “Nexus Java PVP” for Minecraft bedrock was deleted and I still got it and will be putting it in this Repository 




Key Features

• Java Combat & Mechanics: Attack cooldowns, sweep particles, critical hit effects, offhand item support, shield mechanics (blocking via holding right-click), mace slam mechanics, and wind-charge boosts.
• PvP HUD: Custom display elements for armor durability, shield status, hunger/saturation, potion effects, attack cooldown indicators, and keystrokes.
• Customization: Configurable knockback, item-switching styles (via sneaking or emotes), and crosshair settings.
